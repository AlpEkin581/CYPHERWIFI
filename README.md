# ⚡ Cyberpunk Wi-Fi & Network Manager (v3.1)

Windows için geliştirilmiş, harici hiçbir kütüphane gerektirmeyen (`pip install` gerektirmez), terminal tabanlı bir Ağ ve Sistem Yönetim Aracı.

### 🛠️ Özellikler
- 🔑 Kayıtlı Wi-Fi şifrelerini ve detaylarını görüntüleme
- 📱 Mobil bağlantı için otomatik Wi-Fi QR kod dizesi üretme
- 📡 Çevredeki canlı Wi-Fi ağlarını tarama (BSSID/Sinyal Gücü)
- 🖥️ Yerel ağdaki (LAN/WLAN) cihazları ve IP/MAC adreslerini tespit etme (ARP Taraması)
- 🛠️ Tek tıkla DNS önbellek temizleme (Flush DNS) ve bağlantı onarımı
- 📄 Tüm ağ geçmişini yerel `.txt` raporu olarak dışa aktarma

### 🔒 Güvenlik & Gizlilik
> **ÖNEMLİ NOT:** Bu araç gösterilen IP adreslerini, şifreleri veya profilleri **hiçbir şekilde üçüncü şahıslarla paylaşmaz**. Tüm veriler sadece sizin yerel bilgisayarınızda işlenir ve saklanır. Dışarıya veri gönderimi (Exfiltration) yoktur.

### 🚀 Kullanım
1. `cypher_wifi.py` ve `calistir.bat` dosyalarını indirin.
2. `calistir.bat` dosyasına çift tıklayarak çalıştırın.
